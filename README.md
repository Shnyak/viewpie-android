# Viewpie Android

Локальный Android-клиент для Viewpie. Не требует Home Assistant, облака или учётной записи.

## Возможности

- Подключение к Raspberry Pi по IP и порту API; адрес сохраняется локально.
- Режим «Как на HDMI-мониторе»: просмотр активной панели или текущей полноэкранной камеры без переключения HDMI.
- Независимый просмотр любой существующей панели на телефоне.
- Независимый RTSP-просмотр отдельных камер.
- Автоматическая ротация нескольких камер, назначенных одному слоту панели, с ручным переключением.
- Переключение панели на HDMI и вывод камеры на HDMI во весь экран с таймаутом.
- Управление выводом Viewpie: пауза, возобновление, возврат к сетке.
- Проверка RTSP-подключения к камере с измерением задержки.
- Просмотр состояния: активная панель, fullscreen, число потоков, температура CPU, uptime, CPU load и Load Average (последние два поля — если сервер их поддерживает).
- Чтение и изменение настроек Viewpie: spacing, фон, pause-off-screen, rotation interval, fullscreen timeout.
- Перечитывание конфигурации без перезапуска.
- Защищённая перезагрузка Raspberry Pi, если сервер сообщает `restart_available=true`; требуется отдельный токен.

## Сборка

Откройте проект в Android Studio с JDK 17 и Android SDK 35. GitHub Actions собирает APK на каждом PR и публикует GitHub Release при появлении новой версии `versionName` в `main`.

## Совместимость и безопасность

- API сервера: `http://<raspberry-pi>:8080`.
- Независимый просмотр идёт напрямую с RTSP-камеры и создаёт дополнительное клиентское подключение. Одновременный просмотр многих ячеек увеличивает нагрузку на сеть и камеры.
- Камерные URL и токен перезагрузки не выводятся в текст интерфейса; токен не сохраняется.
- Не публикуйте HTTP API Viewpie в интернет. Используйте приложение в доверенной локальной сети.
- Пауза Viewpie выводит чёрный кадр и останавливает декодеры, но не означает физическое отключение питания монитора.
- API перезагрузки и метрики CPU/Load Average доступны только в серверных версиях, которые их реализуют. На старом сервере соответствующие элементы будут недоступны.
